🚨 ERROR: "Cannot GET /api/login"
═══════════════════════════════════════════════════════════════════

CAUSE: Trying to access backend on wrong port or Express not running

SOLUTIONS:
  ✓ Make sure Express is running: npm start (in backend folder)
  ✓ Verify it's port 5000: Server running on port 5000
  ✓ Check URL is: http://localhost:5000 (not 8000 or 5500)
  ✓ Restart: Ctrl+C and npm start again

VERIFICATION:
  Open browser: http://localhost:5000/health
  Should NOT work (no health endpoint on Express, which is OK)

🚨 ERROR: "Cannot POST /api/signup"
═══════════════════════════════════════════════════════════════════

CAUSE: Express backend not responding

SOLUTIONS:
  ✓ Is Express running? (check terminal for "Server running on port 5000")
  ✓ Is MongoDB connected? (check for "✅ Successfully connected")
  ✓ Is .env file created with MONGO_URI?

  ✓ Port 5000 already in use? (netstat -ano | findstr :5000)

  2. Check backend/.env exists with valid MONGO_URI
  3. Run: npm install
  4. Run: npm start
  5. Wait for both messages before testing

🚨 ERROR: "Connection refused" or "Cannot connect to server"
═══════════════════════════════════════════════════════════════════

CAUSE: One or more required services not running

CHECKLIST:
  ☐ Is Express running on port 5000?
    → Check for: "🚀 Server running on port 5000"
  
  ☐ Is Flask running on port 8000?
    → Check for: "Running on http://0.0.0.0:8000"
  
  ☐ Is Frontend accessible on port 5500?
    → Check for: "Serving HTTP on 0.0.0.0 port 5500"
  
  ☐ Are all 3 terminal windows still open?
    → If closed, services stopped

ACTION PLAN:
  1. Check all 3 terminals are open and running
  2. Check terminal output for any RED errors
  3. If services crashed, look at error message
  4. Restart the service that crashed
  5. Try again


═══════════════════════════════════════════════════════════════════
🚨 ERROR: "MongoDB connection error" or database not working
═══════════════════════════════════════════════════════════════════

CAUSES:
  • MongoDB URI in .env is invalid
  • MongoDB cluster is paused/offline
  • IP not whitelisted in Atlas
  • Username/password wrong

FIXES:

1. VERIFY .env FILE:
   File should exist: backend/.env
   Content should have: MONGO_URI=mongodb+srv://...
   
   If missing, copy from backend/.env.example and add credentials

2. CHECK MONGODB URI:
   Format: mongodb+srv://username:password@cluster.mongodb.net/?appName=name
   
   Replace:
   - username: your MongoDB username
   - password: your MongoDB password
   - cluster: your cluster name (e.g., "project-cluster")
   - name: your app name

3. VERIFY MONGODB ATLAS:
   Go to https://www.mongodb.com/cloud/atlas
   
   ✓ Cluster is running (should show "Active")
   ✓ IP is whitelisted (Security → Network Access)
   ✓ Database user exists (Security → Database Users)

4. TEST CONNECTION:
   In terminal, run:
   mongosh "your_mongo_uri_here"
   
   If successful, MongoDB is accessible

🚨 ERROR: "Port 5000 already in use" or "Address already in use"
═══════════════════════════════════════════════════════════════════

CAUSE: Another program is using the port

SOLUTIONS FOR WINDOWS:

1. FIND WHAT'S USING THE PORT:
   netstat -ano | findstr :5000
   
   Returns: TCP ... :5000 ... LISTENING [PID]
   Remember the PID number

2. KILL THE PROCESS:
   taskkill /PID [number] /F
   
   Replace [number] with the PID from step 1

3. TRY AGAIN:
   npm start (in backend)

ALTERNATIVE:
   Change port in server.js:
   From: const PORT = 5000;
   To:   const PORT = 5001;
   
   (But then change frontend URLs too!)

🚨 ERROR: "CORS policy: Response to preflight request"
═══════════════════════════════════════════════════════════════════

CAUSE: CORS not enabled or misconfigured

SOLUTIONS:
  ✓ Make sure flask-cors is installed:
    pip install flask-cors==4.0.0
  
  ✓ Make sure CORS is enabled in app.py:
    from flask_cors import CORS
    CORS(app)
  
  ✓ Make sure CORS is enabled in server.js:
    const cors = require('cors');
    app.use(cors());
