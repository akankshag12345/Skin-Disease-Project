  Terminal 1: cd backend && npm start
  Terminal 2: cd backend && python app.py
  Terminal 3: cd frontend/demo && python -m http.server 5500
  
  Then visit: http://localhost:5500

    TROUBLESHOOTING THE DASHBOARD:
════════════════════════════════════════════════════════════════════════

❌ Dashboard not loading at all?
   ✓ Check if npm is installed: npm --version
   ✓ Check if you're in backend folder: pwd
   ✓ Try: npm install (to ensure all dependencies)
   ✓ Check port 3000 is free

❌ Services show STOPPED but won't start?
   ✓ Check MongoDB .env is configured
   ✓ Check model10class.keras exists in backend/
   ✓ Look at browser console (F12) for errors
   ✓ Check dashboard logs panel

❌ "Cannot find module" error?
   ✓ Run: npm install
   ✓ Run: pip install -r requirements.txt
   ✓ Restart control-server

❌ Logs not appearing?
   ✓ Check if services actually started
   ✓ Refresh browser page (F5)
   ✓ Wait a few seconds for logs to populate
   ✓ Check browser console for JS errors
